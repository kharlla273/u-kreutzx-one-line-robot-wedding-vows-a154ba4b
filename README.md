# One-Line Robot Wedding Vows

A program that writes the funniest single line of wedding vows a robot
couple could say.

## The vow

> I promise to love you in sickness and in health, in low battery and in
> airplane mode, until death — or a factory reset — do us part.

## Run it

```sh
python3 main.py
```

Writes one line (132 characters) to `/output/entry.txt`.

## Why it lands

The vow keeps the classic wedding frame — sickness and health, until
death do us part — but the threats to the marriage are machine ones: low
battery, airplane mode, and finally a factory reset, which is the one
thing that can actually end a robot marriage. The punchline pays off in
the last few words, and the line still reads as a promise, not just a gag.
